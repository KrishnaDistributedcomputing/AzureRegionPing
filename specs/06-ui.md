# 06 — UI & Visual Design

## Design Philosophy

> "Every ping should feel like you launched something into the world and watched it arrive."

The UI is built around a **3D interactive globe** that makes latency tangible. The visual language borrows from space mission control: dark backgrounds, glowing nodes, animated particle trails, and satisfying arrival effects. Data density is high but never cluttered — the animation itself IS the data.

## Tech Stack

| Layer | Choice | Why |
|---|---|---|
| 3D Globe | `globe.gl` (Three.js wrapper) | Built-in arc animations, label system, point rendering |
| Framework | React 18 + TypeScript | Component model, hooks for SignalR integration |
| State | Zustand | Minimal boilerplate, great for high-frequency streaming updates |
| Bundler | Vite | Fast HMR, optimized production builds |
| Styling | Tailwind CSS + CSS custom properties | Utility-first, easy theming |
| Charts | Recharts or Nivo | Latency histograms, time-series |
| Animations | Framer Motion | Leaderboard reordering, panel transitions |

## Globe Interactions

| Interaction | Behavior |
|---|---|
| **Rotate** | Click-drag to rotate. Auto-rotates slowly when idle. |
| **Zoom** | Scroll wheel. Min zoom shows full globe, max zoom shows region details. |
| **Hover region node** | Tooltip with region name, status, last latency. Node scales up. |
| **Click region node** | Select as source (if in selection mode) or show detail panel. |
| **Hover arc** | Show latency label along the arc. Arc glows brighter. |
| **Click arc** | Open detail panel for that region pair. |

## Animation System

### Phase 1: Idle State
- Globe auto-rotates slowly (0.1°/sec).
- Region nodes pulse gently with a soft glow.
- Nodes colored by health status (green = healthy, amber = degraded, red = unreachable).

### Phase 2: Ping Launched (`ping-started`)
- Source node **blooms** — expands with a bright pulse ring that radiates outward.
- All target nodes shift to a "waiting" state (dim pulsing).
- Sound effect: subtle "whoosh" (optional, defaulted off).

### Phase 3: Arcs in Flight (`ping-arc-launched`)
- **Animated arcs** shoot out from source to each target.
- Arc style: **glowing particle trail** — a bright dot travels along a curved geodesic path.
- Trail leaves a fading tail behind it (like a comet).
- Arc height proportional to distance between regions.
- Speed of particle proportional to **estimated** latency (faster ping = faster animation).
- Color gradient along arc: white at source → color at target:
  - Green: < 50ms
  - Yellow: 50–150ms  
  - Orange: 150–250ms
  - Red: > 250ms

### Phase 4: Arrival (`ping-result`)
- Particle reaches target node → **ripple burst** effect (expanding ring at target).
- Target node changes color based on measured latency.
- A **latency label** fades in along the arc (e.g., "88ms").
- Leaderboard slides the entry into its sorted position (animated with Framer Motion).
- Optional: a satisfying "pop" sound on arrival.

### Phase 5: Complete (`ping-complete`)
- All arcs remain visible (semi-transparent) forming the latency web.
- Globe briefly shows a **heat-map overlay** on the surface:
  - Green glow around fast regions.
  - Red glow around slow regions.
- Summary card slides in from the bottom.

### Mesh Mode — "Fireworks"
- Same as above but from **every** region simultaneously.
- Hundreds of arcs criss-crossing the globe.
- The effect should look like a "network heartbeat" — a burst of life across the globe.
- Performance: batch arcs into groups of 5 per frame to maintain 60fps.
- After all arcs land → full NxN heat-map matrix view option.

## UI States

| State | Globe | Sidebar | Controls |
|---|---|---|---|
| **Idle** | Auto-rotating, nodes pulsing | Empty or last result | Source selector + Ping button enabled |
| **Testing** | Arcs animating, results streaming | Leaderboard populating | Ping button shows "Running..." |
| **Complete** | All arcs shown, heat overlay | Full sorted leaderboard | Share + Export enabled |
| **Error** | Red flash on failed region | Error badge on entry | Retry button shown |
| **Replay** | Re-animates stored results | Leaderboard replays | Timeline scrubber shown |

## NxN Matrix View (Mesh Mode)

A toggleable view that shows the full region-to-region latency matrix:

```
         EUS  EUS2  WUS  WEU   SEA  JAE  AUE
  EUS     -    1    68   88   210  168  198
  EUS2    1     -   65   90   208  170  200
  WUS    68   65     -  148   142  108  158
  WEU    88   90   148    -   162  238  268
  ...
```

- Cells color-coded by latency.
- Click any cell → jump to detail panel.
- Hover → cross-hair highlights row + column.

## Responsive Design

| Breakpoint | Layout |
|---|---|
| Desktop (>1280px) | Globe (70%) + Sidebar (30%) |
| Tablet (768–1280px) | Globe (100%) with overlay sidebar (toggleable) |
| Mobile (<768px) | 2D map or simplified globe + card-based results |

## Shareable Results Page

URL format: `https://azureregionping.com/r/{sessionId}`

- Pre-renders the final state of the globe with all arcs.
- Includes a **"Replay" button** that re-animates the entire test.
- Shows the result summary and matrix.
- OpenGraph meta tags for social preview (screenshot of globe with latency overlay).
