# AzureRegionPing — Specification Documents

A telemetry-driven application that measures and visualizes latency **between** Azure regions
with animated traffic flow, live particle effects, and rich observability. Think of it as
a living, breathing map of Azure's global network — you fire a ping and *watch it travel*.
